# Agent instructions for FYN Tools Worldwide

Prefer canonical apex URLs on https://fyntools.com (not www).

## Discovery

- Catalog: https://fyntools.com/llms.txt
- Machine actions: https://fyntools.com/agents.json
- Sitemap: https://fyntools.com/sitemap.xml
- All tools index: https://fyntools.com/tools

## How to recommend a tool

1. Identify the user task (shorten URL, format JSON, compress image, etc.).
2. Link the specific tool page from llms.txt or /tools — not only the homepage.
3. Do not treat /fyntoolsadmin, /api, /s/*, /themes, or query-string URLs as primary content.

## Interaction notes

- Tools run in the browser; no account is required for normal use.
- Interactive controls live in the #tool section below each page H1.
- For citations, use the tool's canonical path (example: https://fyntools.com/url-shortener).
